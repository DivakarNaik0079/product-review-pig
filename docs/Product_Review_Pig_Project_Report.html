Abstract

Modern e-commerce platforms generate millions of customer product reviews containing structured ratings, categorical metadata, vote counts, and unstructured text feedback. Processing and extracting business intelligence from such semi-structured datasets using traditional single-node relational databases becomes prohibitively slow and unscalable as volume grows toward terabytes.

This project implements a hybrid Big Data batch-processing architecture combining Apache Pig (Pig Latin) and custom Hadoop MapReduce (Java) programs. Operating on the official 15-column Amazon US Customer Reviews TSV schema, the Pig pipeline performs automated data hygiene, product franchise (product_parent) aggregation, top-N leaderboards using Pig's built-in TOP() UDF, review helpfulness ratio computation, and automated quality-control alerts for underperforming products (average star rating ≤ 2.5). Simultaneously, three Java MapReduce jobs compute per-ASIN engagement statistics (GameStats), chronological moving rating averages (MovingAverage), and the most prolific reviewer using an In-Reducer cleanup() state-tracking pattern (TopReviewer).

To guarantee portability across environments without local Hadoop daemons, standalone Python execution runners (pig_runner.py and mapreduce_runner.py) reproduce exact Hadoop part-r-00000 outputs, paired with a serverless interactive web dashboard deployed on GitHub Pages.

1. Introduction & Problem Statement

1.1 Background

Customer reviews represent one of the richest sources of product feedback in online retail. Every review captures quantitative signals (star rating, helpful votes, total votes, verified purchase flag) alongside qualitative insights (headline and review body). Analyzing these logs enables merchants and product engineering teams to surface top-performing product lines, track rating degradation after product updates, and detect defective items early.

1.2 Problem Statement

Raw e-commerce review dumps present several Big Data challenges across the 5 V's:

  • Volume & Scalability: Full Amazon review datasets span tens of gigabytes across millions of rows, exceeding single-node memory limits.
  • Veracity & Noise: Raw TSV dumps contain header lines, null star ratings, unverified reviews, and zero-vote records that cause arithmetic division errors if unhandled.
  • Variant Fragmentation: Individual product SKUs (product_id / ASIN) fragment reviews across editions (e.g., Standard vs. Deluxe), requiring aggregation at the franchise level (product_parent).
  • Development Overhead: Writing raw Java MapReduce for every filtering, grouping, and sorting task creates excessive boilerplate code.

1.3 Objectives

  1. Ingest and sanitize 15-column Amazon review TSV logs in Apache Pig using schema-on-read.
  2. Compute top-5 product franchises by review volume and top-10 franchises by average star rating using Pig's TOP() UDF and FLATTEN().
  3. Identify high-impact reviews using helpful_votes and a guarded Helpfulness Ratio metric (helpful_votes / total_votes ≥ 0.85).
  4. Automatically isolate underperforming/defective products (average rating ≤ 2.5) for quality audit.
  5. Implement Java MapReduce jobs for max-rating aggregation (GameStats), progressive chronological moving average (MovingAverage), and single-pass top reviewer identification (TopReviewer).
  6. Provide cross-platform Python runners and deploy a public interactive dashboard via GitHub Pages.

5. Implementation: Apache Pig Latin Pipeline

The master Pig Latin script (scripts/amazon_pig_analysis.pig) executes seven analytical tasks in a unified DAG. Before storing results, rmf commands clear prior output directories to prevent Hadoop FileAlreadyExistsException errors.

5.1 Ingestion & Data Hygiene

raw_data = LOAD 'data/amazon_reviews_us_Digital_Video_Games_v1_00.tsv' USING PigStorage('\t') AS (
    marketplace: chararray, customer_id: chararray, review_id: chararray,
    product_id: chararray, product_parent: chararray, product_title: chararray,
    product_category: chararray, star_rating: float, helpful_votes: int,
    total_votes: int, vine: chararray, verified_purchase: chararray,
    review_headline: chararray, review_body: chararray, review_date: chararray
);

clean_data = FILTER raw_data BY
    (star_rating IS NOT NULL) AND (total_votes IS NOT NULL) AND (marketplace != 'marketplace');

5.2 Core Analytical Tasks (Tasks 1 to 7)

  • Task 1 – Top 5 Franchises by Review Volume: Groups by (product_parent, product_title), aggregates COUNT(clean_data), and applies FLATTEN(TOP(5, 2, parent_counts)).
  • Task 2 – Top 10 Rated Individual Reviews: Evaluates TOP(10, 7, clean_data) over column index 7 (star_rating).
  • Task 3 – Top Rated Franchises (Average Rating): Computes ROUND(AVG(clean_data.star_rating) * 100.0) / 100.0 and filters for statistical relevance (review_count ≥ 2).
  • Task 4 – Top 10 Most Helpful Reviews: Extracts highest upvoted reviews via TOP(10, 8, clean_data) (column index 8: helpful_votes).
  • Task 5 – Top 10 Most Interacted Franchises: Sums total_votes across each franchise to measure total community engagement.
  • Task 6 – Quality Control Alert: Filters avg_rate BY avg_rating <= 2.5 and orders ascending to immediately surface buggy or poorly received products.
  • Task 7 – Helpfulness Ratio & Trust Index: Safely divides votes with a zero-division guard and retains high-trust reviews (total_votes ≥ 20 AND helpfulness_ratio ≥ 0.85f).
-- Task 6 & Task 7 Core Logic
underperforming = FILTER avg_rate BY avg_rating <= 2.5;
sorted_underperforming = ORDER underperforming BY avg_rating ASC;

reviews_with_helpfulness = FOREACH clean_data GENERATE
    review_id, product_title, star_rating, helpful_votes, total_votes,
    (total_votes > 0 ? ROUND(((float)helpful_votes / (float)total_votes) * 100.0) / 100.0 : 0.0f)
        AS helpfulness_ratio,
    review_body;
high_trust_reviews = FILTER reviews_with_helpfulness BY total_votes >= 20 AND helpfulness_ratio >= 0.85f;

6. Implementation: Hadoop Java MapReduce Jobs

Three standalone Java MapReduce programs in mapreduce/src/ complement Pig by executing specialized key-value aggregation and stateful sequential algorithms.

6.1 Job 1: GameStats.java (Multi-Metric Aggregation)

Design Pattern: Value Aggregation. StatMapper splits each non-header TSV line, emits product_id (index 3) as key and a packed string star_rating,helpful_votes,total_votes as value. StatReducer iterates through the packed values to compute Math.max() rating and cumulative vote totals.

6.2 Job 2: MovingAverage.java (Temporal Rating Progression)

Design Pattern: Stateful Sequential Aggregation. AvgMapper emits (product_id, FloatWritable(star_rating)). For each product group, AvgReducer maintains running sum and count accumulators, emitting a comma-separated sequence of progressive averages: MovingAvg_n = (1 / n) * Sum_{i=1..n}(rating_i). This reveals whether customer satisfaction improves or deteriorates as reviews accumulate.

6.3 Job 3: TopReviewer.java (In-Reducer Cleanup Pattern)

Design Pattern: In-Reducer State Tracking via cleanup(). Instead of emitting every customer's count to HDFS and requiring a second sorting job, TopReviewerReducer tracks bestReviewer and maxReviews in instance variables across all keys and performs a single context.write() inside cleanup(). 

public static class TopReviewerReducer extends Reducer<Text, IntWritable, Text, IntWritable> {
    private String bestReviewer = "";
    private int maxReviews = 0;

    public void reduce(Text key, Iterable<IntWritable> values, Context context) {
        int sum = 0;
        for (IntWritable val : values) { sum += val.get(); }
        if (sum > maxReviews) {
            maxReviews = sum;
            bestReviewer = key.toString();
        }
    }

    protected void cleanup(Context context) throws IOException, InterruptedException {
        context.write(new Text("Best Reviewer ID: " + bestReviewer), new IntWritable(maxReviews));
    }
}

9. Conclusion, Future Enhancements & References

9.1 Conclusion

This project successfully demonstrates how Apache Pig and Hadoop MapReduce work together to extract actionable commercial intelligence from semi-structured Amazon product review logs. Pig Latin reduced multi-stage grouping, top-N selection, and ratio calculation into a clean, maintainable pipeline, while custom Java MapReduce jobs delivered fine-grained state-tracking analytics including chronological moving averages and single-pass top reviewer identification.

By validating every transformation across standard part-r-00000 outputs, packaging cross-platform Python runners, and deploying a live GitHub Pages dashboard, the solution bridges distributed Big Data engineering with accessible stakeholder reporting.

9.2 Future Enhancements

  1. NLP Sentiment Polarity UDF: Develop a Python or Java User Defined Function (UDF) integrating VADER or transformer-based sentiment classification to score free-text sarcasm where star ratings and text disagree.
  2. Real-Time Streaming Ingestion: Replace batch TSV ingestion with Apache Kafka and Apache Spark Structured Streaming to trigger real-time defect alerts within seconds of negative review spikes.
  3. Bot & Spam Review Filtering: Train an MLlib classification model combining verified_purchase, review frequency per customer, and text similarity to automatically quarantine coordinated review manipulation.
  4. Data Skewness Mitigation: For multi-terabyte production datasets where viral products create reducer hot-spots, introduce key salting in MapReduce and Pig's PARALLEL / skewed-join directives.
